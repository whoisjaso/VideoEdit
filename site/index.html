The edit

Cut like the best reels, every time.

The recipe was decoded frame by frame from reference reels and written as code. Every sound cue carries the rule that placed it.

  • Dead air cut, your pauses kept. A cold open on the payoff line.
  • A hook title with a bass hit and a camera shake in the first second.
  • Raw, word-by-word captions. Gold for the idea, mint for money and wins, coral for problems.
  • Punch zooms with a whoosh. Slow-mo on the curse punchlines.
  • “seven thousand dollars” becomes a $7,000 pop-up with the register sound.
  • A riser that ends exactly on the payoff, a follow card with the bell, a moody grade, -14 LUFS.
  • Words the recognizer wasn't sure of are flagged, never guessed.

An auto-edited clip from raw phone footage. No hand editing.

For agents

An editor Claude can drive.

Premiere's sequence model stripped to the primitives an agent needs: one JSON timeline per clip, every edit addressed by spoken words, 28 MCP tools. The video never passes through a chat, so the 30 MB wall is gone.

claude mcp add kairos -- python -m kairos mcp

It learns

Score a clip. It learns your taste.

A 1–10, a few quick fixes (“more zooms”, “keep more pauses”) or just a sentence. Each one tunes the style within safe limits and writes a lesson the next edit follows. Keep a streak and watch the average climb.

The mark

The hour, and the moment lifted out of it.

Kairos is the Greek word for the right moment, as opposed to chronos, clock time. The ring is the hour of footage. The gold slice is the forty seconds worth posting. The app wears the same colours the clips do.

Gold, the keyword Mint, the win Coral, the problem Ink Paper
Get started

Up in two minutes.

Python 3.10+ and ffmpeg. Add an Anthropic API key in Settings for sharper picks; it works without one.

git clone https://github.com/whoisjaso/VideoEdit && cd VideoEdit
pip install -e ".[all]"       # Whisper captions, face reframe, links
python -m kairos serve       # http://localhost:8787
