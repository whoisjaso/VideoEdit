# Theta Identity: the script

How to read this file (build.py reads it this way):

- `> line` is an **identity statement**. It is spoken, shown faintly on screen, then followed by
  silence so you can say it back in your head and see it.
- `~ line` is **narration**: spoken only, with a short gap after it. It is used for the scenes.
- `[N]` is **N seconds of silence**.
- `# NAME` starts a block. build.py puts the blocks in order for the night and morning versions.

The rules for every line:

1. First person. "I", never "you". It is my voice in my own head.
2. Plain words. If a ten-year-old can't picture it, cut it.
3. Identity, not ego. Every line is about what I do when nobody is watching, never about how I look.
4. Scenes go in as memories. "I remember this." Then I'm inside it, in the present tense, seeing it
   through my own eyes. Then "That happened. I was there." That is how the brain files a vision
   next to real memories.
